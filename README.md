# invest-notes

私人投資資訊庫（由「投資分析」bot 持續整理）。內容來自《股癌》、《游庭皓的財經皓角》、Threads @jackieyutw。

## 目錄

| 資料夾 | 內容 |
| --- | --- |
| `knowhow/` | 主持人判斷邏輯主題卡 |
| `notes/` | 每集／每日 Threads 一分鐘重點 |
| `predictions/` | 可驗證預測與計分 |
| `research/` | 專題追蹤（例如資安族群） |
| `threads/` | Threads 原文存檔 |
| `transcripts/` | 節目逐字稿（私人，勿外傳） |

預測是方向判斷，不是買賣建議。
