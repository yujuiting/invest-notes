# Knowhow 知識庫

把《Gooaye 股癌》（謝孟恭）、《游庭皓的財經皓角》（游庭皓）與 Threads @jackieyutw 裡**主持人實際講過**的判斷邏輯，整理成可重複使用、可被預測驗證的條目。涵蓋台股、美股與國際情勢。

## 原則
- **只記主持人真的說過的話**，不腦補、不延伸。主持人只是轉述他人（例如轉述聯準會主席）時，在「誰說的」註明「轉述」。
- 推論若是整理者自己加的，必須寫在括號並標「（整理者註）」，或乾脆不寫。
- 逐字稿疑似誤聽的字，照原文保留並標「疑為…」，對照 `../glossary.txt`。

## 卡片格式
每個主題一張 Markdown 卡（檔名＝主題）。每條 entry：

```markdown
## <代碼> <短標題>
- **邏輯**：一到兩句，盡量寫成「如果 X，則傾向 Y」。
- **誰說的**：主持人名（轉述他人時註明）
- **來源**：《節目》日期〈集名〉，約 15–20 分（Threads 則放貼文連結）
- **提及次數**：N（累計；之後每集再提到就 +1，並在來源補一行）
- **狀態**：未驗證 / 被預測支持 / 被推翻
```

- **代碼**：卡片前綴＋流水號（利率-01、資金-02…），一經給定不改，預測的 `sources` 用它引用。
- **時間範圍**：逐字稿每 5 分鐘一個 `[HH:MM:SS]` 標記，寫成「約 15–20 分」。
- **同一邏輯再次出現**：不要新增條目，在原條目「來源」加一行、提及次數 +1；若說法改變，在條目下加「- **看法變化**：日期＋內容」。
- **狀態更新規則**：
  - 引用此條目的預測命中 → 可改為「被預測支持（P-xxxx 命中）」；
  - 引用此條目的預測未中、或主持人自己改口 → 「被推翻（原因）」；
  - 單一預測結果只是弱證據，請在狀態後註明依據的預測 id，累計多次再下定論。
  - 原則類（心法）無法回測，維持「未驗證（原則，不可回測）」。
